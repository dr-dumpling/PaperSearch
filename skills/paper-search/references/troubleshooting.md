# When search commands fail

| Situation                                    | What to do                                                                                                                                                   |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Command not found                            | Install it with the user's consent, as "When only the Skill is installed" in `management-layer.md` says                                                       |
| Windows PowerShell blocks `paper-search` or `npm` (script execution policy) | Use `paper-search.cmd` and `npm.cmd` instead; do not change the execution policy |
| On Windows, `--json-args` reports `is not valid JSON` | PowerShell removed the double quotes in the argument: write the JSON to a file and pass `--json-args '@<file path>'` |
| API key or email missing                     | Tell the user three things: which key this capability needs; where to apply (the address in the error or in `paper-search doctor --format text`); after applying, run `paper-search setup <KEY>` in their own terminal to enter it, then `paper-search config test <KEY>` to confirm it works. When school subscription downloads are installed and the user is at this computer, you can also run `paper-search settings <KEY>` to open the settings window for the user to fill in (when it is not installed or there is no graphical interface, it returns an error with the terminal command). Once the key is entered, rerun the original command. |
| Google Scholar returns CAPTCHA/429 or an unusual-traffic page | Scholar is a best-effort source: `0.5 RPS` by default, successful results cached, stops at once on a verification page. Wait a while, then retry with `--platform googlescholar --max-results 1`; if needed, configure an authorized `GOOGLE_SCHOLAR_PROXY_URL`. It is not in the default `--sources all` list |
| Google Scholar still unavailable, and no key wanted | Use `paper-search search "<search terms>" --sources no-key --max-results 5 --pretty` (Crossref, PubMed, Europe PMC, arXiv, OpenReview)                        |
| 429 rate limit                               | Lower `--max-results`, switch platform, or suggest configuring an optional key                                                                               |
| 0 results                                    | Broaden the keywords, use English synonyms, switch platform, or widen with `--sources`                                                                       |
| Download failed                              | Use the unified `download_with_fallback` and report each attempt; failures involving the school's access are handled by the failure classes in `browser-download.md` |

Scholar settings: `SCHOLAR_RATE_LIMIT_RPS` (default `0.5`), `SCHOLAR_MAX_RETRIES` (default `2`), `SCHOLAR_TIMEOUT_MS` (default `15000`). Only adjust them in the more conservative direction. Scholar is for finding individual papers and topping up small searches; for batch searches use PubMed, Crossref and OpenAlex. Stop at a verification page and try again after a while.
