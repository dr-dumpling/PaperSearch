# 学校订阅下载：各学术身份联盟支持情况

本表说明学校订阅下载能经哪些学术身份联盟登录（截至 2026-11-14）。“支持”是说：用户说出学校名称，程序能查出学校所属的联盟，并在出版社网站上自动选好联盟和学校，走到学校的登录页。登录之后能否下到全文，取决于学校的订阅，以及出版社是否给这所学校开通了学校账号登录。

各国的学术身份联盟通过 eduGAIN 互联，出版社借此认可各国学校的账号；OpenAthens 是跨国的机构登录服务，没有加入本国联盟的学校不少经它登录。

- 配置时只需说出学校名称（中文、英文或当地语言），所属联盟由程序判断，不要问用户是哪个联盟。
- 不在下表任何联盟里、也没有接入 OpenAthens 的学校（只能用校园网、VPN 或图书馆代理访问），暂时无法使用。
- 出版社只给某校开通了 IP、VPN 或机构邮箱方式，或出版社的机构列表里没有这所学校时，程序会写明原因，不再等待。
- 用户问“我的学校能不能用”：先按本表说明学校所属的联盟是否支持，再说明具体能否下到全文要看学校订阅和出版社的开通情况；出版社一侧见 `publisher-support.md`。

符号：✓ 已实测（自动走到学校登录页）；○ 已支持，尚未实测。

按大洲和区域列出：亚洲（东亚、东南亚、南亚、中亚、西亚）→ 欧洲（西欧、北欧、中欧、南欧、东欧）→ 美洲（北美洲；拉丁美洲和加勒比）→ 大洋洲 → 非洲。

## 说明

- 联盟内学校数取自 eduGAIN 登记的身份提供方数量，一所学校可能登记不止一个。
- 学校登录服务器连不上，或学校认证服务器拒绝出版社的登录请求时，程序立即结束并说明“学校登录系统出错”；这类情况要由学校处理。
- 学校登录服务器没有登记这家出版社时（页面显示 Unsupported Request、Metadata not found 等），程序立即结束并说明学校没有为这家出版社开通。

## 学校登录不上时

- 先按程序给出的原因如实告诉用户（各原因的处理见 `browser-download.md` 和 `school-setup.md`）。出版社只给这所学校开了 IP、VPN 或机构邮箱方式，或出版社的机构列表里没有这所学校时，要由学校或出版社开通，程序这边改不了。
- 下面几种情况请用户反馈，维护者据此补联盟或修规则：配置时找不到学校、或回复 `federation_not_supported`；学校所属联盟已支持，下载时却没走到学校登录页（停在出版社选校页、选中了别的学校、学校登录页没被认出）；本表标“○”的联盟的实际使用结果，成功或失败都可以反馈。
- 反馈方式：GitHub 上用“学校登录不上 / 想支持我的学校”模板提 Issue（`https://github.com/dr-dumpling/PaperSearch/issues/new?template=school-login.yml`），写明学校名称和官网域名、所在国家或地区、配置时程序的回复；登录不上的，再写出版社、一篇用户有权限的文章 DOI、停在哪一页和程序给出的原因。可以附上用户核对过的失败记录包（`paper-search failures --export ./failure-report.zip --doi <DOI>`）。
- 不要向用户索要账号、密码、学号或验证码，也不要把带登录参数的网址、Cookie、原始诊断文件写进反馈。
